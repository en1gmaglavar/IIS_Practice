# Протокол замеров: чанкинг и качество поиска (практика 2)

## Исходные данные

В корпусе 4 PDF-документа, регламентирующих учебный процесс и жизнь студентов РТУ МИРЭА. Файлы расположены в `data/raw/`:

1. `Положение о старосте учебной группы.pdf`
2. `Положение о стипендиальном обеспечении.pdf`
3. `Правила внутреннего распорядка в общежитиях.pdf`
4. `Правила внутреннего распорядка обучающихся.pdf`

Суммарный объём — 78 страниц. Документы содержат как сплошной текст, так и нумерованные списки пунктов.

## Словарь рубрик

Рубрика присваивается на основе имени файла (приоритетное правило) и ключевых слов в тексте чанка. Рубрика по умолчанию — `general`.

| Рубрика | По какому правилу присваивается |
| --- | --- |
| `starosta` | Имя файла содержит «старост»; либо в тексте есть слова «старост», «учет посещаемост», «журнал», «ведомост» |
| `scholarship` | Имя файла содержит «стипенди»; либо в тексте есть слова «стипенди», «выплат», «социальн», «материальн» |
| `dormitory` | Имя файла содержит «общежити»; либо в тексте есть слова «общежити», «прожива», «комнат», «комендант», «пропускной» |
| `discipline` | Имя файла содержит «распорядка обучающихся» или «ПВР»; либо в тексте есть слова «распоряд», «поведени», «пропуск», «заняти», «аудитори» |
| `general` | Рубрика по умолчанию: если ни одно из правил выше не сработало |

## Замеры

| № | CHUNK_SIZE | CHUNK_OVERLAP | Чанков в индексе | hit-rate@5 | hit-rate@1 |
| - | ---------- | ------------- | ---------------- | ---------- | ---------- |
| 1 | 512 | 64 | 201 | 100% (4 из 4) | 100% (4 из 4) |
| 2 | 256 | 32 | 389 | 100% (4 из 4) | 100% (4 из 4) |

**Выбранные значения и основание.**

Приняты значения CHUNK_SIZE = 512 и CHUNK_OVERLAP = 64, так как при них достигнут максимальный показатель hit-rate@5 = 100% и они являются стабильными средними значениями (при CHUNK_SIZE = 256 и CHUNK_OVERLAP = 32 чанков много и они содержат в себе малое кол-во информации).

## Уточнение метрики из технического задания

На практике 1 было объявлено провизорное целевое значение `hit-rate@5 = 75%`. Первый фактический замер (при 512/64) показал `hit-rate@5 = 100%`, что превысило целевое значение.
